bibdocqmd / HOSTED PILOT

Use bibdocqmd in Word for the web

Add citations and generate references from your BibTeX files. Start with a small pilot in your browser.

1. Install in Word for the web

Download the add-in file
  1. Download the add-in file above. Keep it as an XML file.
  2. Open a document in Word for the web.
  3. Choose Home → Add-ins → More Settings → Upload My Add-in. Select the downloaded XML file and choose Upload. Menu labels can vary.
  4. Open the bibdocqmd pane using its ribbon button or Word's Add-ins menu.

No developer tools, local server, or certificate setup is needed on your computer.

If Upload My Add-in is missing, your organization may restrict custom add-ins. This page cannot change that setting. See Microsoft's installation instructions.

2. Try the sample

Download the sample Word document and its matching bibliography. These contain fictional demonstration references.

  1. Open the sample DOCX in Word for the web, then open bibdocqmd.
  2. Under Select BibTeX libraries, choose demo.bib.
  3. Try Show formatted citations and Show editable keys.
  4. To add references, put the cursor at the end, choose Entire document → Insert marker, then Update in Word.

3. Use your own bibliography

Select your .bib file, search for a citation key, and choose Insert new. To edit a citation, place the cursor inside it and use Load selected citation, then Update selected.

After reopening Word, select local bibliography files again. The document keeps citation identities and references; the add-in does not embed your whole local bibliography.

Selected bibliography files are read locally in the pane. bibdocqmd does not upload their contents to its host.

QMD export is experimental / in development and currently on hold. Focus this pilot on inserting, editing, saving/reopening, and updating citations and bibliographies. Simultaneous coauthoring remains unverified.
